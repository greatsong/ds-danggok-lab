# 데이터 과학 실습실

당곡고 2026 『데이터 과학』 팀 프로젝트 수업용 스트림릿 앱입니다. 한 팀이 AI와 대화하며 뇌졸중 데이터를 살펴보고 전처리하는 과정을 단계별로 보여 줍니다. 대화마다 학생이 보낸 프롬프트, AI가 준 코드, 그 코드를 이 화면에서 실제로 실행한 결과가 차례로 나타납니다.

## 페이지

| 프로젝트 단계 | 페이지 | 상태 |
|---|---|---|
| ② 데이터 살펴보기·전처리 | `pages/1_데이터_살펴보기.py`, `pages/2_전처리.py` | 완성 |
| ③ 모델 후보·베이스라인 | (예정) | 준비 중 |
| ④ 평가지표·결과 | (예정) | 준비 중 |
| ⑤ 해석·한계 | (예정) | 준비 중 |

## 구조

```
main.py              첫 화면(프로젝트 흐름과 페이지 안내)
pages/               왼쪽 메뉴의 페이지(파일 이름 앞 숫자 순서)
lab/engine.py        모의 채팅 진행기(시나리오를 한 단계씩 보여 주고 코드를 실행)
content/*.json       시나리오(대사·코드·정리 표). 앱 코드와 내용을 나눠 둔다
requirements.txt     필요한 라이브러리
```

화면에 보이는 코드와 실행하는 코드는 같은 문자열입니다. 시나리오의 코드를 고치면 결과도 함께 바뀝니다.

## 페이지 더하기

1. `content/<이름>.json`에 시나리오를 씁니다. 형식은 `lab/engine.py` 맨 위 설명을 따릅니다. 앞 페이지에서 이어지는 변수는 `setup`에 적습니다.
2. `pages/3_<제목>.py`를 만들고 `run_chat("<이름>")`을 부릅니다.
3. `content/home.json`의 해당 단계에 페이지를 적습니다.

## 실행

```bash
pip install -r requirements.txt
streamlit run main.py
```

## 데이터

캐글 Stroke Prediction Dataset(fedesoriano), 5,110명 12열. 수업용 사본 `https://raw.githubusercontent.com/greatsong/modudata/main/data/stroke.csv`을 읽습니다.

## 문장

화면 문장은 솔라 프로4가 설계서를 받아 쓰고, 수치·코드·열 이름은 데이터로 확인했습니다.
