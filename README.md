# 데이터 과학 실습실

당곡고 2026 『데이터 과학』 팀 프로젝트 수업용 스트림릿 앱입니다. 한 팀이 AI와 대화하며 뇌졸중 데이터를 살펴보고, 전처리하고, 모델을 만들어 평가하고 해석하는 과정을 단계별로 보여 줍니다. 대화마다 학생이 보낸 프롬프트, AI가 준 코드, 그 코드를 이 화면에서 실제로 실행한 결과가 차례로 나타납니다.

## 페이지

| 프로젝트 단계 | 페이지 | 상태 |
|---|---|---|
| ② 데이터 살펴보기·전처리 | `pages/1_데이터_살펴보기.py`, `pages/2_전처리.py` | 완성 |
| ③ 모델 후보·베이스라인 | `pages/3_모델_후보.py` | 완성 |
| ④ 평가지표·결과 | `pages/4_평가지표.py`, `pages/5_모델_원리.py` | 완성 |
| ⑤ 해석·한계 | `pages/6_해석_한계.py` | 완성 |

## 구조

```
main.py              첫 화면(프로젝트 흐름과 페이지 안내)
pages/               왼쪽 메뉴의 페이지(파일 이름 앞 숫자 순서)
lab/engine.py        모의 채팅 진행기(시나리오를 한 단계씩 보여 주고 코드를 실행)
content/*.json       시나리오(대사·코드·정리 표). 앱 코드와 내용을 나눠 둔다
requirements.txt     필요한 라이브러리
```

화면에 보이는 코드와 실행하는 코드는 같은 문자열입니다. 시나리오의 코드를 고치면 결과도 함께 바뀝니다.

모델 후보와 모델 원리 페이지 끝의 '구술 인터뷰 대비' 카드에 있는 질문은 구술 평가 루브릭(`2026-ds-danggok/curriculum/구술평가_루브릭.json`)의 문구를 그대로 옮긴 것입니다. 루브릭의 질문이 바뀌면 카드도 함께 고칩니다.

## 페이지 더하기

1. `content/<이름>.json`에 시나리오를 씁니다. 형식은 `lab/engine.py` 맨 위 설명을 따릅니다. 앞 페이지에서 이어지는 변수는 `setup`에 적습니다.
2. 기존 페이지 파일을 복사해 `pages/<번호>_<제목>.py`를 만들고 `run_chat("<이름>")`의 이름만 바꿉니다. 페이지 머리의 몇 줄은 진행기(`lab/engine.py`)가 바뀌었으면 다시 읽게 하는 장치입니다. 스트림릿 클라우드는 새 커밋을 받아도 이미 불러온 모듈을 그대로 쓰기 때문에, 이 장치가 없으면 진행기를 고친 뒤 앱을 다시 시작해야 합니다.
3. `content/home.json`의 해당 단계에 페이지를 적습니다.

## 실행

```bash
pip install -r requirements.txt
streamlit run main.py
```

## 라이브러리 버전

`scikit-learn`만 1.9.1로 고정했습니다. 화면의 설명문은 실행 결과의 수치를 그대로 옮긴 것인데, 랜덤 포레스트의 결과가 버전에 따라 달라지기 때문입니다(1.8.0에서는 재현율 0.80, 1.9.1에서는 0.82). 버전을 올릴 때는 설명문의 수치를 함께 확인합니다. 팀 저장소의 `requirements.txt`는 이름만 적습니다.

## 데이터

캐글 Stroke Prediction Dataset(fedesoriano), 5,110명 12열. 수업용 사본 `https://raw.githubusercontent.com/greatsong/modudata/main/data/stroke.csv`을 읽습니다.

## 문장

화면 문장은 솔라 프로4가 설계서를 받아 쓰고, 수치·코드·열 이름은 데이터로 확인했습니다.
